## らぐろぐについて

株式会社COMPLETEのスマホアプリ「らぐろぐ」の Web 版ビルドです。動作の確認用で、
App Store 版とは別物です。

- 記録はブラウザの中だけに保存され、外部へは送信されません
- 検索避け（noindex / robots.txt）を入れています
- 「見本で中を見る」を押すと、見本データが入った状態で中を見られます
